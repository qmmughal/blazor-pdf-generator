# Blazor PDF Generator

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Sample **Blazor Server / WebAssembly** app that generates PDFs with **PdfSharp** and **MigraDoc**.

> **Status:** reference demo / learning sample — not a packaged library.

## Features

- Blazor Server and WebAssembly sample projects
- PDF generation via PdfSharp + MigraDoc
- Layouts with fonts, images, and tables

## Prerequisites

- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0) (or newer compatible SDK)
- Visual Studio 2022 / Rider / VS Code + C# Dev Kit

## Getting started

```bash
git clone https://github.com/qmmughal/blazor-pdf-generator.git
cd blazor-pdf-generator
dotnet build BlazorSharpProject.sln
```

Open the solution, pick the Server or WebAssembly project, and run it to generate a sample PDF.
